## Overview

TransitLens is an interactive web dashboard that helps transit agencies, policy-makers, and riders understand and improve urban transit systems in Toronto, with a strong emphasis on **equity** and **operational efficiency**.

The platform combines open GTFS data, Statistics Canada census data, and synthetic ridership modelling to surface insights across five analytical modules.

## Features

| Module | Description |
|---|---|
| **Dashboard** | KPI overview — ridership, equity scores, disruption index, forecast accuracy |
| **Equity Scoring** | Transit equity score per neighbourhood using census demographics + stop density |
| **Ridership Demand** | ML-predicted vs actual demand by hour, station heatmap, route load factors |
| **Disruption Simulation** | Click a station to simulate disruption, see cascading impacts and top 3 alternatives |
| **Service Gap Analysis** | Identifies underserved areas, proposes new stops, shows before/after coverage impact |

## Data Sources

All data is open/public or synthetically generated. **No PII is used.**

| Dataset | Source | Licence |
|---|---|---|
| TTC GTFS Feed | [open.toronto.ca](https://open.toronto.ca/dataset/ttc-routes-and-schedules/) | Open Government Licence – Toronto |
| Statistics Canada Census | [statcan.gc.ca](https://www12.statcan.gc.ca/census-recensement/index-eng.cfm) | Statistics Canada Open Licence |
| OpenStreetMap | [openstreetmap.org](https://www.openstreetmap.org) | ODbL 1.0 |
| Synthetic Ridership | Generated by team (Python) | N/A — no PII |

Synthetic ridership data is generated using realistic Gaussian demand curves anchored to TTC GTFS route/stop structure. No individual travel records or PII are used or simulated.

## Running Locally

### Prerequisites

- Node.js >= 18
- npm >= 9

### Steps

```bash
# 1. Clone the repository
git clone https://github.com/adityashoor/TransitLens.git
cd TransitLens

# 2. Install dependencies
npm install

# 3. Start development server
npm run dev
```

Open http://localhost:5173 in your browser.

### Build for production

```bash
npm run build
npm run preview
```
